## Animation Breakdown (What Moves When)

### Layer 1: Outer Ring 🔄
```
Continuously rotating clockwise
├─ Full 360° rotation every 8 seconds
├─ Smooth, constant rotation
├─ Gold color with 30% transparency
└─ Represents: Blockchain network layer
```

### Layer 2: Middle Ring 💫
```
Pulsing in and out
├─ Scales from 100% → 115% → 100%
├─ 2-second cycle (continuous)
├─ Gold color with 50% transparency
└─ Represents: Block confirmation rhythm
```

### Layer 3: Animated Blocks 📦
```
Four golden blocks orbiting the center
├─ Move outward in cardinal directions (N, E, S, W)
├─ Appear → Move Out → Disappear
├─ Each starts 0.75 seconds after the previous
├─ 3-second cycle per block
├─ Create orbital path around M logo
└─ Represents: New blocks being created
```

### Layer 4: Connection Lines 🔗
```
Lines connecting block positions
├─ Fade in → Bright → Fade out
├─ 2.5-second opacity cycle
├─ Create a flowing effect
├─ Offset from blocks for visual depth
└─ Represents: Transactions between blocks
```

### Layer 5: Checkmarks ✓
```
Three confirmation checkmarks pulsing outward
├─ Start at center
├─ Scale: 50% → 100% → 150%
├─ Fade in → Visible → Fade out
├─ 1.5-second cycle
├─ Staggered timing
└─ Represents: Successful confirmations
```

### Layer 6: Central M Logo 🎯
```
Static golden M letter
├─ Center anchor point
├─ All animations orbit around it
├─ Stays fixed during all animations
├─ 80x80 golden circle background
└─ Represents: Mallchain core
```

## Technical Animation Details

### Framer Motion Properties Used

```typescript
// Rotation
animate={{ rotate: 360 }}
transition={{ duration: 8, repeat: Infinity, ease: 'linear' }}

// Scaling
animate={{ scale: [1, 1.15, 1] }}
transition={{ duration: 2, repeat: Infinity, ease: 'easeInOut' }}

// Movement
animate={{
  x: [0, cos(angle)*50, cos(angle)*50, 0],
  y: [0, sin(angle)*50, sin(angle)*50, 0],
  opacity: [0, 1, 1, 0]
}}
transition={{ duration: 3, repeat: Infinity, delay: offset }}

// Fading
animate={{ opacity: [0.1, 0.6, 0.1] }}
transition={{ duration: 2.5, repeat: Infinity, delay: offset }}
```
