1. Extract ZIP file
   unzip mallchain-frontend-production.zip

2. Upload to Namecheap
   • Log in to Namecheap → Hosting → File Manager
   • Navigate to public_html/
   • Upload all files from: mallchain-frontend-production/
     - index.html
     - assets/ directory
     - fonts/ directory
     - favicon.svg, mallchain.svg

3. Configure .htaccess (for SPA routing)
   Create/update .htaccess in public_html with:
   
   <IfModule mod_rewrite.c>
     RewriteEngine On
     RewriteBase /
     RewriteRule ^index\.html$ - [L]
     RewriteCond %{REQUEST_FILENAME} !-f
     RewriteCond %{REQUEST_FILENAME} !-d
     RewriteRule . /index.html [L]
   </IfModule>

4. Verify Deployment
   • Visit your domain → Should show MallChain landing page
   • Test "Login" button → /auth?mode=login
   • Test "Get Started" → /auth?mode=signup
   • Check Settings → 10 social platforms visible
   • Admin account → No KYC banners
